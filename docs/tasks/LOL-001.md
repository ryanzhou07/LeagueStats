## LOL-001a — Desktop scaffold

**Owner:** Desktop & Integration Agent

**Scope**
- Initialize a Tauri + React + TypeScript app in `desktop/` (Vite template).
- Placeholder home screen only; no Riot, SQLite, or engine logic.
- Add scripts: `dev`, `build`, `typecheck`, `lint`, `test`.
- Add ESLint, TypeScript strict mode, and one Vitest smoke test that renders the home screen.
- `desktop/README.md` with run instructions.

**Allowed Files**
- `desktop/**` (including `src-tauri/`)

**Acceptance Criteria**
- `npm run typecheck`, `lint`, `test` pass.
- `npm run tauri build` (or `tauri dev`) launches a window showing the placeholder.
- No files changed outside `desktop/`.

**Testing:** the Vitest smoke test; manual launch recorded in the review.

## LOL-001b — C++ engine scaffold

**Owner:** C++ Analysis Engine Agent

**Scope**
- `engine/CMakeLists.txt` (C++20), `engine/src/main.cpp`, `engine/include/`.
- Executable `lol_engine` that takes `--version` and `--ping` and prints JSON to stdout, e.g. `{"schema_version":"0.0.1","status":"ok"}`. Nonzero exit with a JSON error on bad arguments.
- One CTest test that runs the executable and checks the JSON output (GoogleTest or Catch2).
- Dependency manager manifest (vcpkg or Conan) listing OpenCV and FFmpeg as **declared but not yet linked**.
- `engine/README.md` with build instructions.

**Allowed Files**
- `engine/**`

**Acceptance Criteria**
- `cmake -S engine -B build && cmake --build build && ctest --test-dir build` passes.
- `lol_engine --ping` outputs valid JSON; bad args exit nonzero.
- No files changed outside `engine/`.

**Testing:** CTest covering `--ping`, `--version`, and invalid argument.
