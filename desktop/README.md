# Desktop (Tauri + React + TypeScript)

Placeholder scaffold (LOL-001a). Requires Node >= 22.12 and Rust (stable).

```sh
npm install
npm run tauri dev                  # launch the app window
npm run tauri build -- --debug     # compile a debug .app (macOS: src-tauri/target/debug/bundle/macos)
npm run typecheck | lint | test    # checks
```
